# RICOHFLEX instax back

![RICOHFLEX instax back](photos/hero.jpg)

A source-available conversion kit that enables **Ricohflex** twin-lens reflex cameras to use **instax mini** film.

This repository contains the design files, technical drawings, bill of materials, and manuals required to build the kit.

The project is primarily based on 3D-printed parts, but several critical components require metal fabrication. It is intended for makers with basic machining tools and fabrication experience.

---

## Compatible Cameras

This kit is designed for Ricohflex models equipped with a **helicoid focusing mechanism**.

Verified compatible models:

- RICOHFLEX III
- RICOHFLEX VI
- RICOHFLEX VII
- RICOHFLEX VII S
- RICOHFLEX Holiday

**This kit is not compatible with the RICOHFLEX Dia.**

---

## Repository Structure

### `data`

Contains all files required to build the kit.

- **bom** – Bill of Materials
- **parts** – STL, STEP, and technical drawings
- **assembly** – Complete assembly model (STEP)
- **extras** – Optional accessories such as lens hoods and filter adapters

### `manual`

Contains assembly instructions and the user manual.

---

## Getting Started

1. Review the **Bill of Materials (BOM)**.
2. Manufacture the required parts using the STL, STEP, and drawing files.
3. Assemble the kit by following the Assembly Guide.
4. Read the User Manual before use.
